# 操控说明

适用正式工程fpga/music_controller/music_controller.gprj；Top标识control_ui_v24_top保持原样。固件路径及完整SHA见根VERSION.json。保留实体控制、GS2延音及全部现有功能，GE3位置音乐表达未开放。

- 板载PT8211和外接PCM5102A同步输出同一份最终左右PCM，无需菜单切换；CH0共同控制。
- Room为固定干声＋更强反射回送，开关与Wet沿用原控件。默认Off/Wet64；Wet0/关闭平滑后回干声。
- DD普通KEY1降八度、KEY2升八度、KEY3切独立DD音色；64档力度一直开启，约0.8秒慢击至快速击键映射轻至重。只到第一触点不发音。
- DD音色/八度不跟随Main TIM。Settings设备/DD页的DD Reload重载公共参数快照；A/B order仅释放全部DD键后可改，正常板保持Normal。
- DD PA9→T21/J9.9，PA10原线可保留P19/J9.11，共地；不需要重刷MCU。DD演奏页显示音色、音区、Vel和Ready/Offline/Paused。
- Looper Record Source停止且不忙时可选Main/DD，另一个键盘仍可现场弹奏。C/手机实时/512场景按原规则暂停DD，返回后全松再弹。
- 原C019/RT1手弹事件录制回传保留；完整Loop手机导出、TF/FAT、LP/HP、Chorus仍暂停。手势GS2已加入本版Top，见顶部新规则。

## 视觉控制（原GS2延音，接线不变）

当前已交付用户授权的 `UI_FIX_GS2_SUSTAIN_ONLY`；准确成品FS与SHA见根VERSION.json。

Settings → Input Diagnostics → Gesture control，EDIT短按开关，复位默认Off。TIM短按进入浏览，摇杆在左栏选Settings，EDIT进入；选Input Diagnostics进入，下移选Gesture control即可。20K T6 TX→60K P16/J9.7，共地、分别供电；R18是I2S输出，禁止接视觉TX。

- 沿用既有整机已经跑通的20K GS2固件与接线，不需要为本次UI修复重刷20K。旧GL1协议仍不兼容。
- 延音由原GS2请求位控制：FIST请求普通延音On，OPEN请求Off；不覆盖KEY11选择性延音。是否在移手后继续锁存取决于20K是否继续发送有效保持请求，本版不新增A侧手势策略承诺。
- KEY10或屏幕普通延音操作夺回手动并关闭视觉；通信中断约100ms回到当前手动值，保留原重装/OPEN与场景隔离规则。
- 录制预备/等待/录制/收尾、加载/C/音游/RT1、512及fault/flush暂停接管；已有Loop层不受现场手势踏板改写，返回后按提示新OPEN。
- **新增位置控制暂缓。** Position显示Unavailable灰色，不显示可调整的Depth/Pitch。即使20K发送GE3位置包，本版也不据此改变声音、主音量或手动弯音；独立真实UART百万拍已核对。
- 原摇杆X弯音、Y颤音和页面内深度/速度按既有整机保留；适用音色与原音源/LFO不变。

## 页面分工与入口（沿用V16）

六栏目依次为 **Perform / Looper / Synth / Library / Analyze / Settings**。
TIM短按进入界面操作，摇杆归中，左栏上下选栏目，EDIT进入。
普通参数按两列布局，摇杆左右相邻、上下跨一行；EDIT进入编辑后旋转，短按结束。
EDIT长按返回父页，再长按回左栏；TIM长按直接回演奏表情，不停止循环。

- 演奏主页：音色、Envelope或适用尾音、普通延音、选择延音、颤音深度/速度、滑音、Room Reverb入口。
  最下方“进入发声设置”集中四谐波保持、发声模式、最短时长、保持上限；灰色项目不适用。
  模式/最短/最长仅吉他、贝斯、A/B适用；四谐波保持仅ID5适用。
- 自定义音色：当前ID5直接进入四谐波；当前ID10直接进入A/B。
  其他音色先显示两个入口，选“四谐波合成”或“A/B波表合成”并按EDIT才切换音色进入。
  顶部按EDIT优先打开当前匹配编辑器；顶部向下先进入两个合成器选择入口，便于改选另一种。
  仅浏览/切栏目不改音色；后端拒绝切换时停留入口并显示原因。编辑页内TIM换其他音色自动返回选择入口。
- 四谐波：目标/生效数值、四条生效幅度柱、固定尺度周期曲线、恢复默认。
  EDIT每格raw16（约Q8一步）；CH1..4全程0..4095映射Q8 0..256。
- A/B：A/B各正弦、三角、柔化锯齿、脉冲四预设；EDIT每格一个形状，混合每格raw64。
  CH1平滑混合0全A至4095全B，CH0独立总量。CH2..4在此不控制音色。
  默认A三角/B柔化锯齿/约50%混合；绿色混合、蓝色A、橙色B三曲线。
  形状在新音锁存；持续音混合Q16每样本最多128，满扫约10.65ms。
  恢复A/B默认不改主音量、四谐波或旧录制；四谐波默认raw[4095,1024,512,256]。
- 声音分析：页面顶部“波形 / 频谱 / 李萨如”三项，摇杆左右选、EDIT确认，上推回顶部栏目。
  波形512个实际输出PCM对、左右共同自动缩放；频谱左声道1024点Hann、128柱，约47Hz..6.01kHz；
  李萨如使用真实左右PCM与同一缩放窗口，左右相同正常为斜线，静音居中。
  分析观察DAC采样端，不能据数字图判断模拟伴音、SNR或声压；没有人为制造立体声。

录制开始冻结A/B表身份和已生效混合、四谐波等patch；录中编辑锁定，结束后现场编辑不改已录层。
合成可视曲线是当前配置的理想周期，不含包络/音量/效果，不冒充全部旧实例的最终输出。


## 评分与脱机引导增量

系统设置焦点7进入独立分量测试，焦点8进入脱机LED引导。摇杆选择项目，EDIT短按动作/进入编辑，再旋转调值；长按返回，TIM长按回演奏。

评分页：启动/自然停止、停止时选择32/64/128/256/512、全部/偶组/奇组/单项，以及首项变频对照。CH0保持总音量。评分运行中原演奏键和Looper音频命令隔离，不能一边演奏或录放一边进入测试；先停止、松键、关点击与引导并等尾音结束。

引导页：开始、暂停/继续、停止回头、循环、移调−24～+24。速度共用全局40～240BPM。当前键绿、下一组蓝、实际按下紫红；停止后恢复音色底色。只引导、不自动发声。

曲库和手机连接步骤见QUICK_START，接线及通信边界见INTERFACES。



## 新增 Envelope 与 Room Reverb

TIM选择钢琴0、Drive Lead4或Four Harmonics5；`Perform → Envelope`进入四参数页。RELEASE在普通演奏任意页面都可调整选中项，底栏短暂显示音色、参数和`New notes`。在Envelope页摇杆选择卡片，EDIT短按进入编辑、旋转调整、再短按结束；与RELEASE共用同一参数选择。长按RELEASE恢复单项，`Reset ADSR`连续两次EDIT恢复当前音色四项。换音色数值保留，复位清除。

| 项 | 单位/方向 | 精确默认：钢琴 / Drive / 四谐波保持关 |
|---|---|---|
| Attack | 01..16，递增更慢 | 07 / 03 / 07 |
| Decay | 01..16，递增更慢 | 12 / 15 / 12 |
| Sustain | 0..100%，递增更高 | 50% / 约85% / 50% |
| Release | 01..16，递增更慢 | 14 / 09 / 14 |

档号不是毫秒；底层步长 `[2048,1024,512,256,128,96,68,48,24,16,12,6,4,3,2,1]`。默认Drive的S原始56000保持不变，旋转后才进入整数百分比网格。设置只作用于之后的新音；已按音、尾音和已录Looper层不串改。四谐波与弯音仍可实时改变持续音。录制/预备/收尾、练习、512状态锁定包络编辑，底栏提示原因；长按恢复后松手不会额外切项。

`Perform → Room Reverb`提供`Room enable`与`Room amount`。默认Off、原始Wet64，范围0..128、每格8；屏幕按0..128归一化显示0..100%，表示反射回送强度，不是最终湿声百分比；原始64对应50%。选中Room enable短按EDIT直接开关；Wet卡短按EDIT开始/结束数值编辑，旋转调值。

本版共享增强Room保持干声原增益，叠加更强的反射回送，使用原四comb/阻尼/共享乘法器。Wet0或Off在参数平滑结束后与原干声相同；高Wet与高电平极端叠加仍可能削波。鼓/节拍器保持辅助干声；512旁路并清旧尾音，C场景沿用进入时全局效果。既有整机已获用户对Wet改善的正向反馈；本次只做提交整理，未新增听感或模拟测量。


## Library：持久曲库、音游与原事件录制

Library主界面是4行×2列：

| 左 | 右 |
|---|---|
| Open game：进入音游，不自动发声 | Choose song：EDIT进入浏览、旋转选上一/下一、短按结束 |
| Start / pause：从头播放/暂停/继续 | Stop song：停止曲目来源，保留RAM |
| Capture：原手弹事件录制/Key Map | Return Perform：停止、松键、等安静后返回普通演奏 |
| Load selected：确认加载所选Flash曲目 | Refresh library：刷新目录或核对未知任务 |

上方Selected和下方Selected ID／Notes均是当前预览Flash项目，Loaded只表示FPGA实际RAM曲目；两者可以不同。浏览不会加载或修改现有曲目。进度只表示收到字节，完成需MCU任务/id与本机RAM generation一致。FPGA复位或512借用共享池后，Flash列表还在，但RAM需重新加载。Flash最多32首，FPGA仍一次一首。

TIM短按进入浏览，摇杆归中、左栏选Library，EDIT进入；摇杆按卡片位置移动。Load前停止Loop/歌曲、关点击/LED引导、释放Main/DD及延音并等尾音结束；不能为加载自动清轨。加载中Main/DD新音、Loop/512/RT1及手势接管受锁定，离页不取消事务。panic可止音但不把尚在写入的传输冒充取消。

手机连接时屏幕LOAD拒绝，提示Disconnect phone；断开后刷新再操作。目录版本变化显示Refresh required。断线/应答丢失显示Result unknown，恢复连接后选Refresh核对；只有明确终态且双方不再写入才解锁，不能把旧曲名当新曲加载成功。必要时重新选择并Load。

Game页显示真实RAM曲名、HIT/MISS/EXTRA/TOTAL、长音下落/判定线与RESULT；曲终最后未命中项立即结算，HIT+MISS=TOTAL，EXTRA独立。只保留Game，旧教学入口不恢复。KEY3仅C场景下播放/暂停；TIM五音色0/3/7/8/9，运行中切换按原契约重开；CH0总量、KEY5曲谱节拍器保留。

Capture/Key Map沿用原C019/RT1服务：1ms、最长60秒/512次按下，手机持续读取128事件FIFO；这是手弹事件，不含PCM/伴奏/完整四轨Looper。完整Loop手机导出和Flash保存仍暂停，0x70～74与曲库管理协议冲突不能打开。

新曲库使用C的`qinjian.apk`（包名org.fpgamusic.upload）。准确文件/SHA见ARTIFACTS。未接MCU仍可正常使用Main/DD/Loop；首次查询有10秒截止及最多2次重试，约30秒后才最终提示无响应，等待不阻塞音频。

曲名显示：英文曲名直接显示，非ASCII显示Song＋ID；本版取消三首硬编码英文别名。新Flash选择预览显示前8字符，Loaded／Game仍显示前24字符，长名加省略号；外部完整40字节协议和实际RAM身份核对保留。只去掉新Library第24行曲长／重复总数，顶部曲目索引／总数及全部操作保留。
